# When a tool fails

The error text names the cause and, when Tipee can be fixed by hand, ends
with the page to open on the user's instance. Give that link to the user as
is: it points at the integration's own Roles tab when the API could tell
which integration the key belongs to, at the integrations list otherwise.

| Message says                          | Cause                                                                   | Fix                                                                                                                                                                                                                       |
| :------------------------------------ | :---------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| _rejected the API key_                | The key is wrong or belongs to another instance.                        | Re-enter the instance and key in the plugin settings; the linked page lists the integrations and their keys.                                                                                                              |
| _not allowed to use the API yet_      | The integration lacks the authorization that unlocks the API.           | Tick **Configurations générales → "Se connecter avec des applications externes"** on the linked page. If the API itself was never turned on, an admin with the "Responsable API" role does that first at the second link. |
| _lacks the right_ / _refused_         | The integration lacks the module right this operation needs.            | Tick the right the message names in the linked Roles tab; [roles.md](roles.md) maps every tool to its rights.                                                                                                             |
| _is required and it is not activated_ | The module behind this tool is not enabled on the instance.             | Only a Tipee administrator can enable it; tell the user which module.                                                                                                                                                     |
| _Tipee rejected the request_          | Tipee's own validation refused the call; the message quotes its reason. | Adjust the call to the reason.                                                                                                                                                                                            |
| _does not match its API description_  | Tipee changed a response shape.                                         | Run `check`, report which endpoints fail, and suggest updating the plugin.                                                                                                                                                |
| _could not be reached_ / _rate limit_ | Network or throttling, after retries.                                   | Wait a moment and try again.                                                                                                                                                                                              |
