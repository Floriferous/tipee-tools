# When a tool fails

The error text names the cause and the HTTP status, quotes everything Tipee
answered (field errors, conflicting dates…), and, when Tipee can be fixed
by hand, ends with the page to open on the user's instance. Give that link to the user as
is: it points at the integration's own Roles tab when the API could tell
which integration the key belongs to, at the integrations list otherwise.

| Message says                          | Cause                                                                                            | Fix                                                                                                                                                                                                                       |
| :------------------------------------ | :----------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| _refused the API key_                 | The key is wrong, revoked, expired or another instance's; Tipee's reason follows.                | Re-enter the instance and key in the plugin settings; the linked page lists the integrations and their keys.                                                                                                              |
| _not allowed to use the API yet_      | The integration lacks the authorization that unlocks the API.                                    | Tick **Configurations générales → "Se connecter avec des applications externes"** on the linked page. If the API itself was never turned on, an admin with the "Responsable API" role does that first at the second link. |
| _lacks the right_ / _refused_         | The integration lacks the module right this operation needs.                                     | Tick the right the message names in the linked Roles tab; [roles.md](roles.md) maps every tool to its rights.                                                                                                             |
| _is required and it is not activated_ | The module behind this tool is not enabled on the instance.                                      | Only a Tipee administrator can enable it; tell the user which module.                                                                                                                                                     |
| _Tipee rejected the request_          | Tipee's own validation refused the call; the message quotes its reason.                          | Adjust the call to the reason.                                                                                                                                                                                            |
| _could not find it_                   | An id in the call does not exist; the message quotes which.                                      | Re-read the list the id should come from.                                                                                                                                                                                 |
| _does not match its API description_  | Tipee accepted the call but answered in a shape this plugin cannot read.                         | A write may still have gone through: read it back before retrying. Then run `check`, report which endpoints fail, and suggest updating the plugin.                                                                        |
| _rate limit_                          | Throttling, after retries.                                                                       | Wait as long as the message's Retry-After says (a moment otherwise), then try again.                                                                                                                                      |
| _could not be reached_                | Network failure; the message names the cause.                                                    | A non-existent instance name says so: fix it in the settings. Otherwise wait a moment and try again.                                                                                                                      |
| _unexpected error_                    | Tipee failed on its side (HTTP 5xx), after retries for a read.                                   | Wait and try again. Run `check` if it persists.                                                                                                                                                                           |
| _may have applied it_                 | A write failed in a way that does not say whether Tipee applied it. Writes are never sent twice. | Read it back before trying again, or it may be created twice.                                                                                                                                                             |
| _failed on its own_                   | A bug in this plugin, not Tipee's answer.                                                        | Tell the user, quote the message, and suggest reporting it.                                                                                                                                                               |
