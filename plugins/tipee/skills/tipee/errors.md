# When a tool fails

The error text names the cause; this maps each to its fix.

| Message says                          | Cause                                                                   | Fix                                                                                                                                                                                                                                                                                                                                      |
| :------------------------------------ | :---------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| _rejected the API key_                | The key is wrong or belongs to another instance.                        | Re-enter the instance and key in the plugin settings.                                                                                                                                                                                                                                                                                    |
| _has no permissions yet_              | The integration lacks the authorization that unlocks the API.           | At `https://<instance>.tipee.net/hr-core/integrations`, tick **Configurations générales → "Se connecter avec des applications externes"** on the integration. The tools work immediately afterwards. If the API itself was never turned on, an admin with the "Responsable API" role does that first at `/admin/instance/integrations/`. |
| _lacks the permission_                | The integration lacks the module right this operation needs.            | Grant it at `https://<instance>.tipee.net/hr-core/integrations`; [roles.md](roles.md) maps tools to rights.                                                                                                                                                                                                                              |
| _Tipee rejected the request_          | Tipee's own validation refused the call; the message quotes its reason. | Adjust the call to the reason.                                                                                                                                                                                                                                                                                                           |
| _does not match its API description_  | Tipee changed a response shape.                                         | Run `check`, report which endpoints fail, and suggest updating the plugin.                                                                                                                                                                                                                                                               |
| _could not be reached_ / _rate limit_ | Network or throttling, after retries.                                   | Wait a moment and try again.                                                                                                                                                                                                                                                                                                             |
